# Лабораторная работа 6: «Поиск фильмов» (React + OMDb API)

Одностраничное React-приложение (Vite) для поиска фильмов через OMDb API.

## Реализовано
- Поиск фильмов по названию (`?s=...`), состояния `idle`, `loading`, `error`, `success`.
- Запрет повторных запросов во время загрузки и автопоиск с `useEffect` + debounce (500 мс).
- Заглушка постера при `Poster === 'N/A'`.
- Загрузка краткого описания (`Plot`) для каждой карточки через `?i=imdbID` с индикатором загрузки и `AbortController`.
- Пагинация результатов (`page`).
- Фильтрация по году («Год от» / «Год до») на клиенте.
- Сохранение последних 5 поисковых запросов в `localStorage`.

## Настройка и запуск

1. Получите бесплатный API-ключ на [omdbapi.com](https://www.omdbapi.com/apikey.aspx).
2. Создайте файл `.env` на основе `.env.example` и укажите ключ:
   ```
   VITE_OMDB_API_KEY=ваш_ключ
   ```
3. Установите зависимости и запустите проект:
   ```bash
   npm install
   npm run dev
   ```
